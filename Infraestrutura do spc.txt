Infraestrutura do software

Complete Software Stack: 

	- Linguagens de programacao: Java e Typescript
	- Frameworks: Spring e Angular
	- Database: MySQL
	- Sistema Operacional: Windows Server
	- Browsers compativeis: Google Chrom, FireFox, Microsoft Edge

Infrastructure Requirements Recommended:
	- CPU: Intel Core i5 ou equivalente
	- Cores: 2 ou mais
	- HD: 100 GB de espaço disponível (SSD recomendado para melhor performance)
	- Memória: 8 GB RAM ou mais

Integracao com o banco:
	- Servidor do Ldap para autenticacao


Para garantir o máximo desempenho e eficiência na comunicação com as máquinas de personalização de cartões, recomendamos a instalação direta do backend no servidor. Isso é crucial porque o backend é responsável pela comunicação com as impressoras e outros equipamentos, e uma instalação direta elimina a sobrecarga dos containers, assegurando uma operação mais eficiente.

Embora seja possível usar containers, instalar toda a aplicação diretamente no servidor pode simplificar a configuração e oferecer melhor desempenho.

Como alternativa, podemos instalar o backend diretamente no servidor para garantir a eficiência na comunicação com as impressoras e usar containers para o frontend e o banco de dados, aproveitando a flexibilidade dos containers para esses componentes.
